Fusion Drop

Drop shapes. Same shapes merge into bigger shapes. Hit the level-up condition — two of the largest tier — to evolve through 11 themes. Don't let the stack cross the death line.

Game modes

  • Classic — the standard Suika-style run.
  • Zen — no death line. Pure merges. Endless.
  • Speed — 90-second time attack. Max score wins.

Achievements

  • First Merge — drop, collide, merge!
  • Merger — 10 merges in one run
  • Fusion Master — 50 merges in one run
  • Half K — score 500
  • Two Big — score 2000
  • Apex — spawn the largest tier in the current theme

How it's built

Pure browser game. No frameworks, no build step. HTML + CSS + plain JavaScript. Physics and rendering on a single canvas. Server runs Node and stores leaderboard entries in a JSON file.

Credits
